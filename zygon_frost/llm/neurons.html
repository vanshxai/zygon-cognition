3D VIEW - layers are planes along the long axis (layer 0 on the left). Each plane is a grid of cells, 8 neurons per cell (43 x 32 = 1,376 cells = 11,008 neurons).
Bright cell = contains a triggered neuron (brighter = stronger); the strongest 150 triggered cells per layer are drawn (the table above has the full counts). Faint dots = every 3rd untriggered cell, for the plane shape.
Lines join the strongest triggered cells of one layer to the next. They are ILLUSTRATIVE (strongest-to-strongest); the real wiring is the dense weight matrices.
Yellow = the text entering (left). Cyan = neurons triggered. Orange = last 4 layers. Green = the word the model produced (right).
Drag = rotate, wheel = zoom.
