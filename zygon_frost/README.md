# ZYGON Frost

An offline, token-free engineering assistant built around **exact lookup instead of matrix guessing**. Everything runs on one PC with the Python standard library, NumPy and SymPy. No cloud calls, no AI tokens.

ZYGON (formerly "Frost SI") has four working parts and one experiment:

| Part | What it does | Run |
|---|---|---|
| **Frost Lang** | Sentence memory: learns documents and lessons, answers from what it has read, repairs typos, keeps a chat thread | `python llm/si_app.py --engine 3 --port 8840` |
| **Frost Math** | 333 engineering formulas solved **exactly** (fractions, units, put-back check, chains) | `python llm/frost_forms.py --kind math` (port 8860) |
| **Frost Engg** | Finds planes and cylinders (sizes) in a point cloud | `python llm/frost_forms.py --kind engg` (port 8870) |
| **ZYGON chat** | One non-scrolling screen: invoices, warehouse layout, HVAC sizing, any formula, Lang questions | `python llm/zygon_door.py` (port 8890) |
| **Exponent Qwen** (experiment) | Qwen2.5-3B with every weight rewritten as sign x 2^(step/4), run offline | `python llm/exp_weights.py ...` |

A dashboard that starts everything: `python llm/frost_hub.py` then open http://localhost:8800.

## Quick start
```bash
pip install numpy sympy
python llm/zygon_door.py          # then open http://127.0.0.1:8890
```
Type "I want a service invoice", "design a warehouse", "size an air conditioner for 48000 btu" or "current through a resistor". Say "cancel" to leave a job; to fix a value say it again ("hours 12").
Repair and general questions go to Frost Lang, so start it too (port 8840).

Full walkthrough with expected numbers: [docs/zygon_hvac_test_plan.txt](docs/zygon_hvac_test_plan.txt).

## Results recorded so far
- **Lang:** 500 books (70.6 MB, 8.56M words, 425,271 sentences) learned in 20.9 s; 323/323 inputs answered with a sentence.
- **Math:** 1,214 of 1,216 hidden-value cases right, 0 wrong; all 333 formulas right (`model/math_eval.json`).
- **Engg:** 110 of 155 parts matched, 4.6% median size error (`model/engg_eval.json`).
- **Router (angle-QKV):** 79-83% on 47 questions vs 55% for keyword search. Test set written by the builder, not independent.
- **Exponent Qwen:** same top token as the original 90.8% of the time, original's token in its top 5 for 99.6% (5 HVAC repair prompts x 48 tokens, `model/exp_compare.json`).
Raw logs: `model/*/runs.jsonl`, `model/qkv_runs.jsonl`.

## Known gaps
- Frost Lang has no HVAC repair lessons yet; repair answers are weak.
- Frost Engg is not inside the chat (the chat points to its page).
- The exponent Qwen is slower and bigger than the original (13 s/token, 2.9 GB vs 1.9 GB); the exponent form pays off only once the maths is rewritten as adds and shifts.
- The 36 Qwen blocks are mutually uncorrelated (similarity ~0), so one block cannot be stacked N times to replace them.
